# Install Math Quest on iPhone or iPad

This guide is for a grown-up. Safari does not allow Math Quest to install
itself, so the page opens instructions instead of pretending to provide a
one-tap installer.

## Install from Safari

1. Open the official Math Quest address in **Safari**.
2. Tap **Share**.
3. If necessary, tap **More**.
4. Tap **Add to Home Screen**.
5. If **Open as Web App** appears, leave it turned on.
6. Tap **Add**.
7. Open **Math Quest** from the Home Screen once while online.
8. Open the grown-up installation help and wait for **Ready for an offline
   check**.

The icon is installed only on that device. Safari and the Home Screen app can
keep separate local progress. To move existing Safari progress deliberately:
export a private backup in Safari, install and open the app, then import the
backup transactionally in the installed app. The optional nickname is not in
the backup and can be entered again. A paused starting-point check is also not
in the backup.

The current Beta 2 app accepts an exact older schema-2 Public Beta backup and
upgrades it to schema 3 only after complete validation. A new schema-3 backup
does not work in an older schema-2 copy, so update and reopen Math Quest before
restoring it. A rejected backup leaves the installed app's current progress
unchanged.

## Honest offline check

After the app reports that the exact shell is cached:

1. turn on Airplane Mode and make sure Wi-Fi is off;
2. remove Math Quest from the app switcher;
3. cold-launch Math Quest from the Home Screen;
4. reach the home screen;
5. open one disposable Parent Test question, open Help, use a bundled sound,
   and close Parent Test without changing child progress; and
6. reconnect.

On the primary test iPad, repeat after a reboot and complete one ordinary
offline child session, including correction, Help, save, force quit, reopen,
and exact progress verification.

## Recovery

- If this page opened inside another app, copy the address and open it in
  Safari.
- If Share or Add to Home Screen is missing, check Screen Time or device
  management restrictions and ask the device owner.
- Safari Lockdown Mode disables Web Locks needed for fail-closed progress
  protection. Math Quest pauses child play in that configuration. Do not turn
  off a security setting just for the game; use another qualified device or
  non-Lockdown browser configuration.
- A Safari tab can say only that the current window is not standalone; it
  cannot discover whether another Home Screen copy exists.
- If an icon was added with **Open as Web App** turned off, remove it and add it
  again with that option enabled.
- If the app says **Online only** or **Recovery needed**, reconnect, use Retry,
  and reload. Repairing the app shell does not delete valid progress.
- During first setup, **Checking**, **Caching**, or an update error does not
  prove that an offline copy exists; stay online and retry until the separate
  offline status says **Ready for an offline check**. Math Quest says that a
  current offline version remains usable only after that exact active
  readiness has been verified.
- Setup errors use short caregiver instructions and may show a fixed diagnostic
  identifier. They intentionally do not expose browser service-worker URLs or
  scope details.
- If duplicate icons exist, verify which container has the wanted progress,
  export a private backup if needed, then remove the unwanted icon and its
  local website data.

Browser-managed storage can be evicted. Offline readiness is a current-state
check, not a permanent guarantee. Keep an intentional private backup for
progress that matters.
