# Math Quest design-token contract and generated projection

`assets/design/math-quest-design-tokens-v1.json` and its deterministic generated
stylesheet are original Math Quest project work distributed under the
repository MIT License. The JSON file is the sole semantic authority for the
Mathematical Conservatory and Workshop target tokens. The stylesheet is an
exact machine-generated projection and must never be edited directly.

The stylesheet is linked, served, and available offline, but its closed
`--mq-conservatory-*` namespace has no runtime consumers in ART-MIG-02. This
activates the token foundation without changing rendered presentation. Any
consumer is reserved for ART-MIG-03 and must pass the art-design, feature,
tutorial, accessibility, PWA, rendered-equivalence, and release gates.
