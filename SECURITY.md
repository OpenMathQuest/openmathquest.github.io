# Security policy

## Supported version

Security and privacy fixes are accepted for the latest public beta.

## Reporting a vulnerability

Do not open a public issue for a security or privacy vulnerability. Use the
repository's private vulnerability-reporting feature under
**Security → Advisories → Report a vulnerability** after it is enabled.

Use invented data in a minimal reproduction. Do not include a child's name,
backup, learning record, address, school, account information, or identifying
screenshot.

The project will assess the report and publish a coordinated fix or mitigation
when appropriate. No response-time guarantee is made during beta.
